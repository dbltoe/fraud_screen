**Fraud Screen v1.0.2 is out**

The dry run now works. The setup steps say to switch Log Every Screening Decision on, leave the screen switched off for a few days and read what would have been held, but with the screen off nothing was scored or logged. Now every order gets a line in logs/fraud_screen.log ending `WOULD HOLD (dry run)` or `passed (dry run)`, with its score and reasons, and nothing is held. Switched on, nothing changes.

Plugin Manager now has a Forum Support Thread button beside Read Me and GitHub, and the plugin lists Zen Cart 2.3.0.

The readme is clearer on two points. On a store that captures payment, a held fraudulent order is refunded to the card it came from, which belongs to the real cardholder; the old wording read as if the store got the refund. And Square cancels an uncaptured online payment after seven days by default, not six.

**Upgrading:** upload the `v1.0.2` folder beside your current one in `zc_plugins/FraudScreen`, then in Modules > Plugin Manager select Fraud Screen and click Upgrade, then Upgrade again on the confirmation screen. Your settings stay as they are, and Clean Up removes the old folder afterward.
