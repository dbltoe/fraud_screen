**Fraud Screen v1.0.3 is out**

v1.0.3 changes one thing: the Plugin ID in manifest.php is now 2464, the ID the Plugins Library assigned on 6 October. Earlier releases carried a placeholder that we wrote as text ('0') instead of a number, and the Library's tool only updates a number, so it couldn't put the real ID into its copy. That was our mistake. Without the right ID, Plugin Manager had no way to tell you about updates.

There are no screening, code or settings changes, and your held orders and order history aren't touched. You only need this release if you want Plugin Manager to tell you about future updates.

To upgrade, put the v1.0.3 folder beside v1.0.2 in zc_plugins/FraudScreen/ and click **Upgrade** in Admin > Modules > Plugin Manager. On Zen Cart 2.2.0 and later, that's all. On 2.1.x, Plugin Manager keeps the ID it recorded when it first saw the plugin, so also run this line in Admin > Tools > Install SQL Patches (it adds your table prefix itself):

`UPDATE plugin_control SET zc_contrib_id = 2464 WHERE unique_key = 'FraudScreen';`
